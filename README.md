# Chitranjan Kumar Gupta — Portfolio

A personal developer portfolio website engineered with **React.js**, **Vite**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. Built with a dark obsidian aesthetic, warm glowing amber/orange accents, an interactive cyber terminal audio visualizer, responsive layouts, and verified academic and project credentials.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6
- **Language**: TypeScript / JavaScript (ES6+)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Version Control**: Git & GitHub

## ⚡ Local Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Chitranjangupta12/<REPO_NAME>.git
   cd <REPO_NAME>
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables (Optional)**:
   Copy `.env.example` to `.env` if custom variables are needed:
   ```bash
   cp .env.example .env
   ```
   *(Note: The portfolio is designed to work completely out-of-the-box without requiring private environment keys).*

4. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

5. **Build for production**:
   ```bash
   npm run build
   ```

6. **Preview the production build**:
   ```bash
   npm run preview
   ```
